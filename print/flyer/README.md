# Flyer (print-ready)

One-page flyer with the SPTP badge, mission statement, a photo, and a
scannable QR code that opens safeplacetoplay.org.

**Size:** 8.5" × 11" at 300 DPI (standard letter paper).

| File | Use |
|------|-----|
| `SPTP-Flyer.jpg` | For print sites that only accept images |
| `SPTP-Flyer.pdf` | For print shops and emailing |

Print at full letter size, borderless if the printer supports it.
